# 🎁 GiftForge — Telegram Mini App

## 🚀 Быстрый старт (Windows)

### Шаг 1 — Первичная настройка
1. Дважды кликни на **`setup.bat`**
2. Дождись сообщения «Настройка завершена!»
3. Если Node.js не установлен — следуй подсказкам

### Шаг 2 — Запуск
1. Дважды кликни на **`start.bat`**
2. Браузер откроется автоматически
3. Перейди на **http://localhost:5173**

### Это всё! Игра работает в демо-режиме 🎉

## 🤖 Настройка Telegram-бота (необязательно для локального теста)

### 1. Создай бота у BotFather

1. Открой Telegram на телефоне
2. Найди **@BotFather** (с галочкой верификации)
3. Напиши `/newbot`
4. Введи **название** бота: `GiftForge`
5. Введи **username** бота: `твое_название_bot` (должен заканчиваться на `bot`)
6. Скопируй полученный **токен** вида `1234567890:ABC...`

### 2. Узнай свой Telegram ID

1. Найди в Telegram бота **@userinfobot**
2. Напиши ему `/start`
3. Скопируй `Id:` из ответа (число)

### 3. Вставь данные в настройки

1. Открой файл `.env` в папке проекта
2. Замени значения:
   ```
   BOT_TOKEN=твой_токен_здесь
   ADMIN_TELEGRAM_ID=твой_telegram_id
   BOT_USERNAME=имя_бота_без_@
   ```

### 4. Получи публичный HTTPS-адрес

Telegram требует HTTPS для Mini App. Варианты:

**Для разработки (бесплатно):**
- Скачай [ngrok](https://ngrok.com)
- Запусти: `ngrok http 5173`
- Скопируй адрес вида `https://abc123.ngrok.io`

**Для продакшена:**
- Арендуй VPS (например, [Hetzner](https://hetzner.com) ~300 руб/мес)
- Установи nginx + SSL через certbot

### 5. Настрой Mini App в BotFather

1. Напиши BotFather `/newapp`
2. Выбери своего бота
3. Введи название: `GiftForge`
4. Введи URL: `https://твой-адрес.com`
5. Загрузи иконку (640x360 пикселей)

### 6. Вставь URL в .env

```
APP_URL=https://твой-адрес.com
DEMO_MODE=false
```

## 🎮 Как играть

### Кейсы (вкладка 🎁)
- Открывай кейсы за монеты или билеты
- Смотри вероятности выпадения каждого предмета
- Наблюдай анимацию рулетки

### Апгрейд (вкладка 🚀)
- Выбери предмет из инвентаря
- Выбери желаемый предмет лучше
- Нажми «Апгрейд» — шанс зависит от разницы ценности
- При успехе получаешь новый предмет!

### Конкурсы (вкладка 🏆)
- Участвуй в бесплатных розыгрышах
- Победитель выбирается случайно
- Следи за таймером окончания

### Друзья (вкладка 👥)
- Копируй реферальную ссылку
- За каждого приглашённого: +100 монет + 1 билет
- Статистика приглашённых

### Профиль (вкладка 👤)
- Ежедневный бонус (каждые 20 часов)
- Активация промокодов
- Инвентарь и история

## 🌐 Деплой на сервер

### Простой способ — Railway.app

1. Зарегистрируйся на [railway.app](https://railway.app)
2. Создай новый проект из GitHub
3. Добавь переменные окружения из `.env`
4. Укажи URL в BotFather

### VPS (рекомендуется для продакшена)

```bash
# На сервере:
git clone твой-репозиторий
cd my-telegram-bot
npm run setup
npm run build

# Запуск через PM2
npm install -g pm2
pm2 start packages/backend/dist/index.js --name giftforge-api
pm2 serve packages/frontend/dist 3000 --name giftforge-web
```

## ❓ Частые вопросы

**Q: Игра не открывается в браузере?**
A: Убедись, что оба окна (Backend и Frontend) запущены. Подожди 15 секунд после start.bat.

**Q: Ошибка «нет монет»?**
A: Используй промокод WELCOME500 в разделе Профиль.

**Q: Как сбросить базу данных?**
A: Удали файл `packages/backend/prisma/dev.db` и запусти setup.bat снова.

**Q: Бот не отвечает?**
A: Проверь BOT_TOKEN в файле .env.
