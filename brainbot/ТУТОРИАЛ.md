# 🎮 Brain Battle — туториал по запуску

Готовая основа бота в стиле **Brainrot Battle** — с кейсами, навигацией и дизайном 1-в-1.
Мини-игры (Апгрейдер, Дайсы, Краш, Батл) пока в виде заглушки "В разработке".

---

## 📂 Что внутри

```
brainbot/
├── bot.py              # Telegram бот (aiogram)
├── requirements.txt    # Зависимости Python
├── .env.example        # Шаблон настроек
└── webapp/
    ├── index.html      # Мини-апп (все экраны)
    ├── style.css       # Тёмная тема, синие акценты
    └── app.js          # Логика кейсов, открытия, баланса
```

## 🚀 ЗАПУСК С ТЕЛЕФОНА (самый простой способ)

### Шаг 1. Получи токен бота
1. Открой в Telegram → [@BotFather](https://t.me/BotFather)
2. Отправь `/newbot`
3. Придумай имя (например: `My Brain Battle`)
4. Придумай username (должно оканчиваться на `bot`, например: `my_brainbattle_bot`)
5. **Скопируй токен** вида `7123456789:AAE...`

### Шаг 2. Захости WebApp бесплатно (через GitHub + Vercel)

**Вариант А — Vercel (рекомендую, 2 минуты):**
1. Залей папку `webapp/` на GitHub (можешь через мобильное приложение GitHub)
2. Зайди на [vercel.com](https://vercel.com), войди через GitHub
3. New Project → выбери свой репозиторий
4. Root Directory → укажи `brainbot/webapp`
5. Deploy → получишь ссылку вида `https://твой-проект.vercel.app`

**Вариант Б — Netlify Drop (ещё проще):**
1. Открой [app.netlify.com/drop](https://app.netlify.com/drop)
2. Перетащи туда папку `webapp` целиком
3. Получишь ссылку

### Шаг 3. Привяжи WebApp к боту
1. Открой [@BotFather](https://t.me/BotFather)
2. `/mybots` → выбери своего бота → **Bot Settings** → **Menu Button**
3. Отправь свой URL из Шага 2 (например `https://моё.vercel.app`)
4. Название кнопки: `🎮 Играть`

Теперь в боте снизу чата появится кнопка меню, которая открывает мини-апп.

### Шаг 4. Запусти питон-бота (нужен компьютер или облако)

**На компьютере:**
```bash
cd brainbot
pip install -r requirements.txt
cp .env.example .env
# открой .env и впиши туда токен и URL
python bot.py
```

**В облаке бесплатно (чтобы бот работал 24/7):**
- [Railway.app](https://railway.app) — $5 бесплатных кредитов каждый месяц
- [Render.com](https://render.com) — бесплатный тир с засыпанием
- Инструкция: New Project → Deploy from GitHub → выбрать репозиторий → добавить переменные `BOT_TOKEN` и `WEBAPP_URL`

## ✅ Готово!

Открой своего бота в Telegram, нажми `/start` → увидишь кнопку "🎮 Открыть Brain Battle" → откроется мини-апп с:

- **Кейсы** — сетка кейсов (Дракон, Тако, Нубини и т.д.) + топ-дроп, промо-блок, поиск
- **Детали кейса** — выбор ×1/×3/×5, кнопка "Открыть", список возможных дропов, анимация открытия
- **Апгрейд** — заглушка "в разработке"
- **Бесплатно** — сетка бесплатных кейсов
- **Профиль** — меню как в оригинале (Апгрейдер, Дайсы, Краш, Батл, Бонусы, Квесты, Колесо, Розыгрыши)
- **Пополнение** — модалка с вкладками Брейнроты/Гирсы/Звёзды/Рубли

Баланс стартует с **1000 Ⓑ** для теста — открытия кейсов списывают монеты и случайно начисляют приз.

## ❓ Частые проблемы

- **Бот не отвечает** → проверь токен в `.env`, что не было опечаток
- **Кнопка меню не открывается** → URL должен быть `https://` (не `http://`), и сайт должен реально работать
- **Белый экран в мини-аппе** → открой URL в обычном браузере на телефоне, посмотри ошибки
- **"Недостаточно средств"** → это норма, при перезагрузке баланс сбрасывается на 1000
