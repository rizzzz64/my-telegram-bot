# 📱 Запуск Brain Battle с телефона (бесплатно, 24/7)

Весь запуск делается **с телефона**. Нужны только 3 аккаунта (все бесплатные):
- **Telegram** (уже есть)
- **GitHub** — для хранения кода и хостинга WebApp
- **Render.com** — для запуска питон-бота 24/7

Время: ~15-20 минут.

---

## 🧩 Шаг 1. Создай бота в Telegram (2 мин)

1. Открой [@BotFather](https://t.me/BotFather)
2. Отправь `/newbot`
3. Имя: `My Brain Battle` (любое)
4. Username: должен оканчиваться на `bot`, например `my_brainbattle_bot`
5. **Скопируй токен** вида `7123456789:AAE...` — сохрани в заметках, он понадобится 2 раза

---

## 🧩 Шаг 2. Залей код на GitHub (5 мин)

Если у тебя уже есть этот репо (ты смотришь его сейчас) — **пропусти этот шаг**, код уже залит в ветку `ccr-bf9bcd20-j27v2n`. Тебе нужно только смержить в `main`:

1. Открой GitHub в браузере телефона → свой репозиторий `my-telegram-bot`
2. Переключись на ветку `ccr-bf9bcd20-j27v2n`
3. Нажми **"Contribute" → "Open pull request"** → **"Create pull request"** → **"Merge pull request"**

Теперь папка `brainbot/` в `main`.

---

## 🧩 Шаг 3. Захости WebApp на GitHub Pages (3 мин)

GitHub Pages — **бесплатный хостинг для статики прямо из твоего репозитория**.

1. Открой свой репо на GitHub с телефона
2. Нажми **"Settings"** (⚙️ сверху, если не видно — тапни по трём точкам)
3. В меню слева найди **"Pages"**
4. **Source** → выбери **"Deploy from a branch"**
5. **Branch** → выбери `main` и папку `/ (root)` → **Save**
6. Подожди 1-2 минуты, обнови страницу → сверху появится ссылка вида:
   ```
   https://rizzzz64.github.io/my-telegram-bot/
   ```
7. Твой WebApp будет по адресу:
   ```
   https://rizzzz64.github.io/my-telegram-bot/brainbot/webapp/
   ```
8. **Открой эту ссылку в браузере на телефоне** — должен открыться мини-апп с кейсами. Если работает — **сохрани ссылку**, она пойдёт в BotFather.

> ⚠️ Если видишь 404 — подожди ещё 2-3 минуты, Pages деплоится не моментально.

---

## 🧩 Шаг 4. Привяжи WebApp к боту (1 мин)

1. Открой [@BotFather](https://t.me/BotFather)
2. `/mybots` → выбери своего бота
3. **Bot Settings** → **Menu Button** → **Configure menu button**
4. Отправь URL из Шага 3 (полный, с `/brainbot/webapp/` в конце)
5. Название кнопки: `🎮 Играть`

Теперь в чате с ботом снизу появится синяя кнопка **🎮 Играть**.

---

## 🧩 Шаг 5. Запусти бота на Render.com (7 мин)

Render — бесплатно крутит бота 24/7.

### 5.1 Регистрация
1. Открой [render.com](https://render.com)
2. **Get Started** → **Sign in with GitHub** → разреши доступ

### 5.2 Создание сервиса
1. В дашборде нажми **"+ New"** → **"Background Worker"**
   > Берём именно **Background Worker**, а не Web Service — у бота нет веб-страницы, он просто опрашивает Telegram
2. **Connect a repository** → найди `my-telegram-bot` → **Connect**
3. Заполни форму:
   - **Name:** `brainbot` (любое)
   - **Region:** `Frankfurt` (ближе к РФ)
   - **Branch:** `main`
   - **Root Directory:** `brainbot`
   - **Runtime:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python bot.py`
   - **Instance Type:** `Free`

### 5.3 Переменные окружения
Прокрути вниз до **Environment Variables** → **Add Environment Variable**:

| Key | Value |
|---|---|
| `BOT_TOKEN` | твой токен из Шага 1 |
| `WEBAPP_URL` | ссылка из Шага 3 |

### 5.4 Деплой
1. Нажми **Create Background Worker** внизу
2. Подожди 2-3 минуты — Render поставит зависимости и запустит бота
3. В логах должно появиться: `Бот запущен. WebApp URL: https://...`

## ✅ Готово! Тестируем

1. Открой своего бота в Telegram
2. Нажми `/start` → увидишь приветствие с кнопкой **"🎮 Открыть Brain Battle"**
3. Жми либо эту кнопку, либо синюю **🎮 Играть** снизу чата

---

## ⚠️ Важно про бесплатный план Render

- Сервис **не засыпает** на Background Worker-е (в отличие от Web Service)
- Даётся **750 часов в месяц** = хватает на 1 бота 24/7
- Если бот перестал отвечать — зайди на Render → твой сервис → **Logs**, посмотри ошибку

---

## 🔄 Как обновить бота потом

1. Правишь файл на GitHub прямо с телефона (через иконку карандашика)
2. Коммит
3. Render автоматически перезапускает бота через ~1 минуту
4. GitHub Pages обновляется автоматически за ~1 минуту

---

## 🆘 Если что-то не работает

**Бот не отвечает на /start:**
- Render → Logs → смотри ошибку
- Чаще всего — опечатка в `BOT_TOKEN`. Исправь → **Manual Deploy → Deploy latest commit**

**Кнопка "Играть" открывает белый экран:**
- Открой `WEBAPP_URL` в браузере напрямую
- Если там 404 — проверь что GitHub Pages включился (Settings → Pages)
- URL должен быть **https://** (не http://), иначе Telegram заблокирует

**"Недостаточно средств" в мини-аппе:**
- Это нормально. Стартовый баланс 1000 Ⓑ. Перезагрузи мини-апп — сбросится (пока нет БД).
